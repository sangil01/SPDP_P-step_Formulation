## Progress

### Forward labeling based pricing for root-node CG

- Modified reduced arc cost:

$$
w_e = c_{ij} - \delta_{ij} - 2\alpha_j
$$

- Fix the source state

$$
u = (s,\sigma_s)
$$

and initialize labels with state-node, length, cumulative cost, cumulative time, visited locations, and request-class memory.

- Label state:

$$
l = (x, K_l, C_l, T_l, U_l, M_l)
$$

- The implementation tracks:
  - current node/state $x$
  - path length $K_l$
  - cumulative reduced cost $C_l$
  - cumulative time $T_l$
  - visited location set $U_l$
  - highest visited request ID by class $M_l$

### Label extension and dominance

- Extend only along feasible state transitions.
- Apply time feasibility:

$$
T_l + t_e \le T
$$

- Apply the symmetry-breaking rule based on increasing `request_id`.
- Prevent revisiting physical locations.
- Use a dominance rule on labels with the same current node and length:

$$
C_{l_1} \le C_{l_2}, \quad
T_{l_1} \le T_{l_2}, \quad
U_{l_1} \subseteq U_{l_2}, \quad
M_{l_1} \le M_{l_2}.
$$

### Column selection

- Complete labels are evaluated when they reach length $p$, or length at most $p$ when starting from the depot.
- For each start state, keep the most negative `MAX_COLUMNS_PER_START` columns.
- Per pricing round, keep the most negative `MAX_COLUMNS_PER_ROUND` columns.

### Root-node column generation

- Two-phase primal simplex method is used.
- Phase 1 generates initial columns for a feasible root-node solution.
- Phase 2 computes the optimal root-node LP bound.
- Current root-node CG does **not** include VI (35), VI (36), or VI (44).
