## 2. 지표

- $z^*$: 어느 실행에서든 증명된 최적값입니다.
- $z^{\text{ref}}$: $z^*$가 있으면 $z^*$이고, 없으면 F1–F8, Forbes, `SPDP_solution_benchmark` 중 가장 좋은 UB입니다. 즉 알려진 가장 좋은 feasible solution의 값입니다.
- **root gap**: $\text{gap}^{\text{root}}=(z^{\text{ref}}-LB^{\text{root}})/z^{\text{ref}}\times 100$
- **총 시간** (PALNS 포함): $t=(3600-\texttt{instance\_budget\_remaining\_before\_solve})+\texttt{solver runtime}$. 증명하지 못하면 3600입니다.
- **# optimal**, **미증명 LB**, **final gap**: 1시간 안의 증명 수, 그때의 하한과 gap입니다.

## 3. 본문 실험

### 실험 1. Forbes et al. (2026) vs Ours (no AE) vs Ours (AE)

- **실행**: F2, F1. root LB는 R1에서 읽습니다. Forbes는 기존 결과를 씁니다.
- **Forbes 결과**: `SPDP_MILP_benchmark/SPDP_benchmark_fragment_outputs/`
  - 인스턴스별 `RecDep_day_<i>_flex_frag.summary.json`, 전체 표 `final_comparison_paper_baseline_research.csv`, 메모리 초과 목록 `memory_over_32GB.csv`
  - 조건: `fleet=lb` (원래 목적식), 3600초, 8 threads, 메모리 50 GB
  - 상태: 최적 36, 한도(해 있음) 5, 한도(해 없음) 8, routing LP 한도 4, 메모리 초과 14 (C13–C20, D2–D7)
  - 문헌 최선값을 cutoff로 받았습니다(EJOR 2026 Table 6, COR 2022 Table 5). 우리는 PALNS UB만 씁니다. 

| 지표 | Ours | Forbes (`summary.json`) |
|---|---|---|
| graph size | $\lvert E\rvert$. F1은 $\lvert E_1\rvert$, $\lvert E_2\rvert$도 | `"A"` |
| root LB | R1 | `"LB_r"`, `"LB_c"` |
| # optimal | `solved to optimality: 1` | `"status": "optimal"` |
| 미증명 LB | `lower bound` | `"LB"` |
| 시간 | $t$ | `"runtime_total"` |

**가설**
- graph size: Forbes ≫ Ours (no AE) ≫ Ours (AE)
- LB: Forbes ≈ Ours (우리가 조금 강하지만 비슷)
- optimal sol 수: Ours ≫ Forbes
- 시간: Forbes ≫ Ours

### 실험 2. Fleet size VI

- **실행**: R3 (VI 켬) vs R2 (VI 끔). 둘 다 capacity cut을 꺼서 VI 하나의 효과만 봅니다.
- **지표**: root LB, root gap, LP 차량 수 (`departure flow`)
- **가설**: VI가 있으면 LB가 훨씬 큽니다.
  - A1: 648.00 (= 최적값) vs 426.09, LP 차량 수 1.00 vs 0.55
  - B1: 1248.02 vs 917.20, LP 차량 수 2.00 vs 1.33

### 실험 3. Strengthened duration constraint (SDC)

- **실행**
  - full: F1 (SDC) vs F5 (Big-M). 둘 다 AE를 씁니다. 이전 A 묶음 결과(cap cut 끔): 증명 20 → 17, 시간 합 877 → 14,195초
- **인스턴스 분류** (T1의 $z^{\text{TF}}$ 사용)
  - $\mathcal I_{=}$: $z^{\text{TF}}=z^*$ (시간 제약이 최적값을 바꾸지 않음)
  - $\mathcal I_{<}$: $z^{\text{TF}}<z^*$ (시간 제약이 최적값을 올림)
  - $z^*$를 모르면: 증명된 $z^{\text{TF}}$가 가장 좋은 UB와 같을 때만 $\mathcal I_{=}$이고, 그 밖에는 미분류입니다.
- **지표**: # optimal, 시간, 미증명 LB
- **가설**
  - **# optimal**: SDC ≫ no SDC (작은 인스턴스에서도)
  - 시간: $\mathcal I_{=}$에서는 no SDC가 더 빠를 수 있고(모형이 작음), $\mathcal I_{<}$에서는 SDC가 빠릅니다.

### 실험 4. Capacity cut

- **실행**

|       | cut 켬 (root-only) | cut 끔 |
| ----- | ----------------- | ----- |
| AE    | F1                | F3    |
| no AE | F2                | F4    |

- **root**: R1 (켬) vs R3 (끔)
- **지표**: # optimal, 시간, 미증명 LB, root LB, cut 수 (`Capacity blossom cuts added`), separation 시간
- **가설**
  -  **# optimal**, 시간, 미증명 LB, root LB 모두 cut 켬이 낫습니다. cut 수는 꽤 많습니다.
  - AE 행에서는 차이가 작을 것입니다(이전 실행: 증명 수 같음, 시간 −0.3%).
- **adaptive-tree (F7, F8)**:  위의 실험 결과가 좋지 않을 경우 수행합니다.

## 4. 부록 실험

### 부록 A. Fleet size: duration problem vs Forbes et al. (2026) vs COR (2022)

| 방법 | 값 | 시간 |
|---|---|---|
| Ours (duration IP, $k_{\min}=\lceil D^{LB}/T\rceil$) | R1의 `subproblem_k_min` | `subproblem_runtime_seconds` (풀이), `k_min_seconds` (모형 생성 포함 전체) |
| Forbes (차량 최소화 LP, $\hat v=\lceil z^{LP}_{\text{veh}}\rceil$) | `summary.json`의 `"v_hat_initial"` | `<i>_flex_frag.gurobi.log`의 첫 LP 풀이 시간 (`runtime_lp`는 routing LP와 합쳐져 쓸 수 없음) |
| COR (2022) (닫힌 식) | R1의 `cor_k_min` | 사실상 0초 |
| 참고: 해의 차량 수 | F1의 `vehicle count` | — |

- **지표**: 인스턴스별 세 값과 계산 시간, 그리고 해의 차량 수와 같아지는 인스턴스 수입니다.
- 모든 값은 R1 로그의 `[duration-bound]` 줄에 있습니다.
  - `selected_k` = max(COR, duration IP)입니다.
  - `subproblem_status` 11은 $\lceil D^{LB}/T\rceil$가 증명된 순간 멈춘 것으로 정상입니다. 9는 600초 한도입니다(그때의 하한으로 구한 값도 유효).
- 예: C9에서 COR 4, 우리 5, duration IP 1.57초입니다.

### 부록 B. Time-free model

- **목적**
  - SDC: $\mathcal I_{=}$, $\mathcal I_{<}$를 나눕니다(실험 3).
  - AE: Step 2a는 $z^{\text{TF}}\ge U$일 때 바로 최적이 증명됩니다. $U=z^*$이면 이는 $i\in\mathcal I_{=}$와 같으므로, $\lvert\mathcal I_{=}\rvert$가 Step 2a에서 증명되는 인스턴스 수와 같습니다.
- **실행**: T1
  - PALNS는 끕니다. $z^{\text{TF}}$는 시작해와 상관없습니다. 1시간 한도에 걸리는 인스턴스가 많으면 그것만 PALNS를 켜고 다시 돌립니다.
  - fleet size VI는 켭니다. AE 안의 time-free 모형도 이 행을 쓰고, 시간 행이 없으므로 경로 시간 한도는 이 행으로만 반영됩니다.
- **지표**: $z^{\text{TF}}$, 증명 여부, 시간, $z^*-z^{\text{TF}}$, 해의 차량 수
- 예: A1에서 $z^{\text{TF}}=648=z^*$입니다.
