## Reduced cost
### Reduced cost reformulation only fixing start

Let

$$
u = (s,\sigma_s), \qquad v = (f,\sigma_f),
$$

where $s$ is the start location and $f$ is the end location.

For each p-step $r$, the reduced cost is

$$
\bar c_r
=
c_r
- \sum_i a_r^i \alpha_i
- \sum_{i,\sigma} s^{r,i}_{\sigma} \beta_{i,\sigma}
- \sum_{i,\sigma} q^{r,i}_{\sigma} \gamma_{i,\sigma}
- \sum_e b_e^r \delta_e.
$$

Using the p-step structure, this can be rewritten as

$$
\bar c_r
=
\sum_{(i,j)\in P_r} (c_{ij} - \delta_{ij} - 2\alpha_j)
+ t(r)\gamma_v
+ (\gamma_v - \gamma_u)\tau_r
- \alpha_s + \alpha_f - \beta_u + \beta_v.
$$

If

$$
\gamma_v - \gamma_u \ge 0,
$$

then the minimizing choice is

$$
\tau_r = 0.
$$

Otherwise,

$$
\tau_r = T - t(r).
$$

Hence the reduced cost can be decomposed into

$$
\bar c_r = C(P_r) + \Phi(u,v,t(r)),
$$

where

$$
C(P_r) = \sum_{(i,j)\in P_r} (c_{ij} - \delta_{ij} - 2\alpha_j),
$$

and

$$
\Phi(u,v,t(r))
=
t(r)\gamma_v
+ (\gamma_v - \gamma_u)\tau_r
- \alpha_s + \alpha_f - \beta_u + \beta_v.
$$

Here, $C(P_r)$ is the path-dependent cumulated cost, while $\Phi(u,v,t(r))$ is a terminal-dependent cost term.

### Reduced cost reformulation fixing start and end

The above decomposition is for the case where the terminal node is not fixed in advance.

If the terminal state

$$
v=(f,\sigma_f)
$$

is fixed, then after substituting the optimal choice of $\tau_r$, the coefficient of $t(r)$ can be absorbed into the cumulated path cost.

If

$$
\gamma_v - \gamma_u \ge 0,
$$

then $\tau_r=0$, and

$$
\bar c_r
=
\sum_{(i,j)\in P_r} (c_{ij} - \delta_{ij} - 2\alpha_j + \gamma_v t_{ij})
- \alpha_s + \alpha_f - \beta_u + \beta_v.
$$

If

$$
\gamma_v - \gamma_u < 0,
$$

then $\tau_r=T-t(r)$, and

$$
\bar c_r
=
\sum_{(i,j)\in P_r} (c_{ij} - \delta_{ij} - 2\alpha_j + \gamma_u t_{ij})
+ (\gamma_v-\gamma_u)T
- \alpha_s + \alpha_f - \beta_u + \beta_v.
$$

Therefore, once $v$ is fixed, the time contribution can be included in the arc-wise cumulated cost, and the remaining terms become fixed with respect to the path. In that case, the pricing problem becomes an ESPPRC for the fixed terminal state.

## Pricing problem structure

### Motivation

- In the CVRP setting of Dollevoet (2026), the pricing problem is an ESPPRC for each $(s,f)$ pair.
- In SPDP, a direct extension would require one pricing problem for each

$$
(s,\sigma(s), f,\sigma(f)),
$$

$\quad$ which becomes too large.
- In instance `A11`, this generate `479090` pricing problems.
- Fix only the source state

$$
(s,\sigma(s)),
$$

$\quad$ and solve a single-source multi-sink ESPPRC with terminal-dependent reduced cost. i.e., 

$$
\bar c_r = C(P_r) + \Phi(u,v,t(r)).
$$

### Optimization problem

The pricing problem is

$$
\min \bar c_r
$$

subject to:

- p-step feasibility constraints
	- $0 \le \tau_r + t(r) \le T\qquad \text{s.t.} \qquad t(r) = \sum_{e \in P_r} t_e$
	- $v_{e_i} = u_{e_{i+1}} \qquad \forall i = 1,\ldots,q-1$
	- $\sigma(v_{e_i}) = \sigma(u_{e_{i+1}})  \qquad \forall i = 1,\ldots,q-1$
- length constraint
- elementary constraint
- time constraint: $t(r) \le T$
- symmetry breaking constraint based on Eq. (43)

## Forward labeling algorithm

### Initialize start label

Define the modified arc cost

$$
w_e = c_{ij} - \delta_{ij} - 2\alpha_j \qquad \forall e=(i,j)\in E.
$$

Fix the source state

$$
u = (s,\sigma_s).
$$

Each forward label is represented by

$$
l = (x, K_l, C_l, T_l, U_l, M_l),
$$

where:

- $x_l  = (i,\sigma(i))$: start node of current label
- $K_l =$ length of $l$
- $C_l = \sum_{e \in l} w_e$: cumulated cost of $l$
- $T_l= \sum_{e \in l} t_e$: cumulated time of $l$
- $U_l =$ visited location set of $l$
- $M_l =$ highest request ID visited at $l$ for each request class, used for the symmetry-breaking constraint (43)

The initial label is
$$
l = (u, 0, 0, 0, \{s\}, \varnothing).
$$
### Label extension with dominance check

For each feasible arc

$$
e = (x,y),
$$

extend the label only if:

- $T_l + t_e \le T$
- $\text{request\_id}(y)$ is larger than the stored maximum request ID in its request class
- $\operatorname{loc}(y) \notin U_l$

Then update:

$$
K'_l = K_l + 1,
$$

$$
C'_l = C_l + w_e,
$$

$$
T'_l = T_l + t_e,
$$

$$
U'_l = U_l \cup \{\operatorname{loc}(y)\}.
$$

For the request-class memory,

$$
M'_{\text{class}(y),l}
=
\max\!\big(M_{\text{class}(y),l}, \operatorname{request\_id}(y)\big).
$$

### Dominance rule

For labels with the same current node $x$ and length $K$,

$$
l_1 \text{ dominates } l_2
$$

if
$$
C_{l_1} \le C_{l_2}, \qquad
T_{l_1} \le T_{l_2}, \qquad
U_{l_1} \subseteq U_{l_2}, \qquad
M_{l_1} \le M_{l_2}.
$$

This rule is exact.

To see this, take any feasible suffix $Q$ that can be appended to $l_2$, and let the resulting terminal state be

$$
v=(f,\sigma_f).
$$

Then the same suffix $Q$ is also feasible after $l_1$ because:

- both labels start the suffix from the same current node-state $x$,
- $U_{l_1} \subseteq U_{l_2}$ preserves elementarity feasibility,
- $M_{l_1} \le M_{l_2}$ preserves symmetry feasibility,
- $T_{l_1} \le T_{l_2}$ preserves time feasibility.

Let

$$
r_1 = P_{l_1} \oplus Q,
\qquad
r_2 = P_{l_2} \oplus Q.
$$

Then

$$
\bar c_{r_1} - \bar c_{r_2}
=
(C_{l_1} - C_{l_2})
+ \Phi(u,v,T_{l_1}+t(Q))
- \Phi(u,v,T_{l_2}+t(Q)).
$$

Although $\Phi(u,v,t)$ depends on the terminal state $v$, it is nondecreasing in $t$ for every fixed $u$ and $v$.
Indeed, from the LP dual,

$$
\gamma_{i,\sigma} \ge 0.
$$

Also, for fixed $t$, the feasible interval of $\tau_r$ is

$$
0 \le \tau_r \le T-t.
$$

Since

$$
\Phi(u,v,t)
=
t\gamma_v + (\gamma_v-\gamma_u)\tau_r
- \alpha_s + \alpha_f - \beta_u + \beta_v
$$

is affine in $\tau_r$, the minimizing choice is attained at an endpoint:

- if $\gamma_v-\gamma_u \ge 0$, then $\tau_r=0$, so

$$
\Phi(u,v,t)
=
\gamma_v t
- \alpha_s + \alpha_f - \beta_u + \beta_v,
$$

whose slope is $\gamma_v \ge 0$;

- if $\gamma_v-\gamma_u < 0$, then $\tau_r=T-t$, so

$$
\Phi(u,v,t)
=
\gamma_u t
+ (\gamma_v-\gamma_u)T
- \alpha_s + \alpha_f - \beta_u + \beta_v,
$$

whose slope is $\gamma_u \ge 0$.

Hence

$$
T_{l_1} \le T_{l_2}
\quad \Longrightarrow \quad
\Phi(u,v,T_{l_1}+t(Q))
\le
\Phi(u,v,T_{l_2}+t(Q)).
$$

Together with $C_{l_1} \le C_{l_2}$, this gives

$$
\bar c_{r_1} \le \bar c_{r_2}.
$$

Therefore every feasible completion of $l_2$ is also a feasible completion of $l_1$ with no larger reduced cost, so the dominance rule is exact.

### Complete label and column selection

A label is complete if:

- $K_l = p$, or
- $K_l \le p$ when the source is the depot state

After computing the reduced cost of each complete label:

- select the most negative `MAX_COLUMNS_PER_START` columns for each start state
- then select the most negative `MAX_COLUMNS_PER_ROUND` columns overall

## Bidirectional labeling algorithm (추후 구현 시 다시 확인, 오류 있을지도)

### Initialization

Use the same modified arc cost

$$
w_e = c_{ij} - \delta_{ij} - 2\alpha_j,
$$

fix the source state

$$
u = (s,\sigma_s),
$$

and build the completion function

$$
\Phi(u,v,t)
$$

for every feasible terminal state $v=(f,\sigma_f)$.

Split the length as

$$
p_F = \left\lfloor \frac{p}{2} \right\rfloor, \qquad
p_B = p - p_F.
$$

### Backward labeling

A backward label is represented by

$$
l_B = (x, K_{l_B}, C_{l_B}, T_{l_B}, U_{l_B}, v),
$$

where:

- $x_{l_B} = x(l_B)$: start node of the current backward label
- $K_{l_B} = K(l_B)$: length of $l_B$
- $C_{l_B} = C(l_B) = \sum_{e \in l_B} w_e$: cumulated cost of $l_B$
- $T_{l_B} = T(l_B) = \sum_{e \in l_B} t_e$: cumulated time of $l_B$
- $U_{l_B} = U(l_B)$: unreachable location set of $l_B$, possibly using DSSR
- $v$: fixed terminal state associated with $l_B$

Initialization:

$$
l_B = (v, 0, 0, 0, \{f\}, v).
$$

### Backward extension and dominance

For each feasible reverse extension

$$
e = (y \rightarrow x),
$$

extend if

$$
T'_{l_B} \le T
$$

and

$$
\operatorname{loc}(x) \notin U_{l_B}.
$$

The tighter condition is

$$
T'_{l_B} + t_{uy} \le T \quad s.t \quad t_{uy} \ is \ SPP \ length \ for \ (u,v).
$$

Update:

$$
K'_{l_B} = K_{l_B} + 1, \qquad
C'_{l_B} = C_{l_B} + w_e, \qquad
T'_{l_B} = T_{l_B} + t_e , \qquad
U'_{l_B} = U_{l_B} \cup \{\operatorname{loc}(x)\}.
$$

For labels with the same $x$ and $K$,

$$
l_{1B} \text{ dominates } l_{2B}
$$

if

$$
\tilde C_{l_{1B}}^{\,u,v} \le \tilde C_{l_{2B}}^{\,u,v}, \qquad
U_{l_{1B}} \subseteq U_{l_{2B}}.\, \qquad
M_{l_1B} \le M_{l_2B}.
$$

Here, $\tilde C_{l_B}^{\,u,v}$ denotes the cumulated modified cost under the fixed-terminal reformulation for the fixed pair

$$
u=(s,\sigma_s), \qquad v=(f,\sigma_f).
$$

More precisely, if

$$
a_{u,v} =
\begin{cases}
\gamma_v & \text{if } \gamma_v - \gamma_u \ge 0, \\
\gamma_u & \text{if } \gamma_v - \gamma_u < 0,
\end{cases}
$$

then

$$
\tilde C_{l_B}^{\,u,v}
=
\sum_{e\in l_B} \big(w_e + a_{u,v} t_e\big)
=
C_{l_B} + a_{u,v} T_{l_B}.
$$

**This rule is exact only after fixing both $u$ and $v$ and absorbing the corresponding time coefficient into the arc cost, so that the backward problem becomes a standard ESPPRC over the remaining resources.**

### Completion function

For a backward label, define

$$
G_{l_B}(t) = C_{l_B} + \Phi(u, v_{l_B}, T_{l_B}+t), \qquad t=T_{l_F}
$$

which is the additional reduced cost contributed when merging with a forward label.

For the same $(x,K_l,v)$, construct the **lower hull**

$$
E_{u,v}(x,K_l,t) = \min_{l_B} G_{l_B}(t).
$$

This function is  **lower envelope** and used:

- before merging,
- or before forward extension when $\operatorname{loc}(u)=0$

If $\operatorname{loc}(u)=0$, compute it at every extension step. Otherwise, compute it when

$$
K_{l_B} = p_B.
$$

### Forward labeling inside the bidirectional algorithm

The forward label is

$$
l_F = (x, K_{l_F}, C_{l_F}, T_{l_F}, U_{l_F}),
$$

with initial label

$$
l_F = (u, 0, 0, 0, \{s\}).
$$

For each extension

$$
e = (x \rightarrow y),
$$

require feasibility in time and elementarity, then update:

$$
K'_{l_F} = K_{l_F} + 1, \qquad
C'_{l_F} = C_{l_F} + w_e, \qquad
T'_{l_F} = T_{l_F} + t_e, \qquad
U'_{l_F} = U_{l_F} \cup \{\operatorname{loc}(y)\}.
$$
### Forward dominance

Use the same exact forward dominance rule as above.  
The terminal dependence of $\Phi$ does not invalidate dominance, because for every fixed terminal state $v$, $\Phi(u,v,t)$ is nondecreasing in $t$.

### Pruning using the completion function

For a forward label, compute a lower bound

$$
LB_u(l_F) = C_{l_F} + \min_{v}E_{u,v}(x, K_{l_B}, T_{l_F}), \qquad x=end \ (node, state) \quad for \quad  l_F
$$

If

$$
LB_u(l_F) \ge 0,
$$

the label is pruned.

- If $\operatorname{loc}(u)=0$, check this at every extension and over all feasible backward lengths.
- Otherwise, check it before merging, with

$$
K_{l_F} = p_F, \qquad K_{l_B} = p_B.
$$

### Merging

Merge a forward label $l_F$ and a backward label $l_B$ if they share the same meeting (node, state) and

$$
K_{l_F} + K_{l_B} = p,
$$

or

$$
K_{l_F} + K_{l_B} \le p
$$

when the source location is the depot.

The merged p-step must also satisfy

$$
t_r \le T.
$$

The merged reduced cost is

$$
C_{l_F + l_B} + \Phi(u_{l_F}, v_{l_B}, T_{l_F} + T_{l_B}).
$$

Additional checks:

- all physical nodes must be unique, satisfying the relaxed symmetry-breaking rule
- if a cycle appears, add duplicated nodes in the cycle to the `ng` set and resolve

### Implementation notes

- If $\operatorname{loc}(u)\neq 0$, store only forward/backward labels with lengths $p_F$ and $p_B$ that are not dominated.
- The pricing problems can be parallelized for each source state $u$.
- Forward and backward label generation can also be parallelized.
- During forward extension, the tighter check

$$
T'_{l_F} + t_{yv} \le T \qquad \forall v
$$

requires pruning information for each terminal state $v$.
