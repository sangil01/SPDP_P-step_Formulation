
For a node pair $(u,v)$, let

$$
E_{uv}=\{e\in E:u_e=u,\ v_e=v\}
$$

be the set of parallel compressed edges. These edges may represent different
state transitions or internal treatment sequences. An integer route can use at
most one of them, so

$$
\left|\{e\in E_{uv}:\theta_e>0\}\right|\le 1.
$$


## Parallel-edge branching

Suppose the fractionally active edges in $E_{uv}$ are partitioned into two
nonempty sets $A$ and $B$. Create two child nodes:

$$
\theta_e=0 \qquad \forall e\in A,
$$

and

$$
\theta_e=0 \qquad \forall e\in B.
$$

This disjunction is valid because an Special Ordered Set of Type 1(SOS1)-feasible integer solution (집합 내에서 최대 하나의 변수만 nonzero일 수 있다는 뜻) uses an edge in at most one of $A$ and $B$. A solution using no edge in $E_{uv}$ is
feasible in both children. Repeated binary partitioning eventually leaves at
most one edge available; it does not create one child for every edge at once.
==The partition can be selected using the current fractional values and can order edges by $(\sigma_e^{\mathrm{start}}, \sigma_e^{\mathrm{end}},\pi_e)$ so that similar transitions remain together.==

## Gurobi SOS1

The parallel-edge condition can be declared to Gurobi as

$$
\operatorname{SOS1}\{\theta_e:e\in E_{uv}\}.
$$

SOS1 means that at most one member may be nonzero; it does not require one
member to be selected. 

For every pair $(u,v)$ with $|E_{uv}|\ge2$, its edges are sorted
lexicographically by $(\sigma_e^{\mathrm{start}},\sigma_e^{\mathrm{end}},\pi_e)$, assigned distinct weights $1,\ldots,|E_{uv}|$.

We test three settings:

- `default`: do not add SOS1 constraints.
- `sos1-auto`: add SOS1 constraints with `PreSOS1BigM=1`, allowing Gurobi to choose the reformulation. 현재 formulation에서는 service node 마다 $\sum_{e\in\delta^+(u)}\theta_e=1$ 이 암묵적으로 성립하므로 $\sum_{e\in E_{uv}}\theta_e \le \sum_{e\in\delta^+(u)}\theta_e =1$. 따라서 $\sum_{e\in E_{uv}}\theta_e \le 1$ 을 추가하는 것인 reformulation은 사실 의미가 없을 것.
- `sos1-native`: add SOS1 constraints with `PreSOS1BigM=0`, disabling SOS1 reformulation so that the SOS1 is used for branching rule.

Result: 그냥 default가 젤 좋았음.
