
## Motivation

In most SPDP instances considered here, the fixed cost per vehicle dominates the travel cost. Using the minimum feasible number of vehicles is therefore essential for obtaining a low-cost solution. Nevertheless, for some instances the original-cost MILP has difficulty finding an incumbent that uses this minimum number, even when VI 44 provides the corresponding route-count lower bound. The resulting weak upper bound can make the reported root-LP gap appear much larger than the weakness of the LP relaxation itself. To address this issue, a feasible solution is first generated by solving a duration-minimization IP with the smallest known vehicle count fixed, and the resulting solution is supplied to the main original-cost MILP as an initial incumbent.

## Fixed-vehicle-count incumbent problem

Let $\mathcal F^{\mathrm{IP}}$ denote the integer feasible region of the time-extended 2-index formulation on the multigraph, and define

$$
K(y)=
\sum_{\substack{e\in E:u_e=0\\v_e\in C^p}}y_e,
\qquad
D(y)=\sum_{e\in E}t_ey_e.
$$

After computing the selected valid lower bound $\widehat k$ for VI 44, the following auxiliary IP is solved:

$$
\begin{aligned}
\min_{y,B}\quad &D(y)\\
\text{s.t.}\quad &(y,B)\in\mathcal F^{\mathrm{IP}},\\
&K(y)=\widehat k.
\end{aligned}
\tag{1}
$$

The duration objective guides the feasibility search; its optimal value is not required. The solver terminates at the first feasible solution. If (1) finds a solution, the validity of $\widehat k$ gives

$$
\widehat k\le k_{\min}^{*}\le K(y)=\widehat k,
$$

and hence $k_{\min}^{*}=\widehat k$. Failure to find a solution within the time limit does not establish infeasibility and the main algorithm simply continues without an initial incumbent.

The selected edge support is decomposed into depot-to-end routes and checked for complete action coverage, state consistency, capacity feasibility, empty terminal states, and the route-duration limit $T$. Its original cost

$$
C(y)=\sum_{e\in E}c_ey_e
$$

is then evaluated and the solution is mapped to the formulation used by the main solver. For the direct 2-index model, the binary edge values are supplied as a complete MIP start. For a $p$-step enumeration master, the recovered routes are decomposed into compatible $p$-step columns; any required valid column omitted by enumeration pruning is restored and its coefficients are appended before the master is constructed. In branch-and-price, the corresponding columns seed the initial restricted master and the recovered route solution supplies the incumbent upper bound.

## 9. Quadratic assignment / bin packing with dummy node

9번은 capacity-1과 무관하게 \(Q=2\)를 그대로 두고 생각하는 것이 좋습니다.

### 9-A. Q=2 matching bin packing with conflicts

기존 VA의 atom \((i,j)\)를 그대로 차량 bin에 배정합니다. 두 atom \(a,b\)만 수행하는 정확한 최소 route duration을 \(\tau_{ab}\)라고 합시다.

\[ \tau_{ab}>T \]

이면 두 atom은 어떤 실제 route에도 함께 들어갈 수 없으므로

\[ \boxed{ \lambda_{aq}+\lambda_{bq}\le1 } \qquad\forall q \tag{B} \]

를 추가할 수 있습니다.

이는

\[ \lambda_{aq}\lambda_{bq}=0 \]

이라는 quadratic co-assignment 정보를 선형화한 것입니다. Conflict clique \(C\)가 있으면

\[ \sum_{a\in C}\lambda_{aq}\le1 \]

로 강화할 수 있습니다. 이러한 conflict graph가 material/aggregate bound가 놓치는 bin-packing loss를 잡는 것은 표준적인 방향입니다. [Bin packing with conflicts 연구](https://www.sciencedirect.com/science/article/pii/S0305054802001958)

더 나아가 master가 차량 \(q\)에 atom 집합 \(A_q\)를 배정하면, 그 집합만 수행하는 정확한 single-route feasibility oracle을 풉니다. 불가능하면

\[ \boxed{ \sum_{a\in A_q}\lambda_{aq} \le |A_q|-1 } \tag{C} \]

을 추가합니다. 가능하면 minimal infeasible subset으로 줄인 뒤 cut을 넣는 편이 강합니다.

이 과정을 완전히 반복하면 logic-based Benders/branch-and-check가 됩니다.

- Fixed \(m\) master가 infeasible: \(\kappa^*\ge m+1\).
- 모든 bin이 route oracle을 통과: 실제 \(m\)-route 해.
- 현재 proven LB부터 검사하면 최초 feasible \(m\)이 exact \(\kappa^*\).

이 방법은 8번과 다릅니다. 두 lane으로 분해하지 않고, 원래 \(Q=2\) bin에 직접 atom을 배정합니다. 또한 모든 atom이 사용된 bin에 명시적으로 배정되므로 기존 vehicle-count flow의 \(K(y)=0\) disconnected-cycle 문제가 없습니다.

주의할 점은 \(\tau_{ab}\)들을

\[ \sum_{a<b}\tau_{ab}\lambda_{aq}\lambda_{bq}\le T \]

처럼 단순 합산하면 안 된다는 것입니다. 세 개 이상의 atom에서 동일한 travel을 여러 번 세므로 일반적으로 유효하지 않습니다. Pair duration은 우선 forbidden-pair 판정에 쓰는 것이 안전합니다.

### 9-B. QAP + dummy separator exact formulation

보다 문자 그대로의 QAP 해석도 가능합니다. 모든 pickup, emptying, delivery action과 \(m\)개의 dummy separator를 하나의 순열에 배치합니다. 두 dummy 사이의 action block 하나가 차량 route 하나입니다.

Position 변수 \(x_{ah}\)를 사용하면 연속 action의 travel은

\[ \sum_h\sum_{a,b} t_{ab}x_{a,h}x_{b,h+1} \]

이라는 QAP 형태가 됩니다. Dummy에서는 state와 time을 empty/zero로 reset하고,

- dummy 다음 action은 pickup,
- dummy 이전 action은 delivery,
- 각 block의 duration은 \(T\) 이하,
- pickup/emptying/delivery precedence,
- type matching과 \(Q=2\) state transition

을 정확히 적용합니다.

그러면 fixed-\(m\) infeasibility는 그대로 \(\kappa^*\ge m+1\)을 증명합니다. Dummy depots로 multiple routes를 하나의 순열 또는 TSP 구조로 바꾸는 방식 자체는 알려진 모델링 기법입니다. [Dummy-depot mTSP formulation](https://www.mdpi.com/2227-7390/11/13/3014)

장점은 disconnected subtour를 구조적으로 없앤다는 것입니다. 단점은 \(3n+m\)개의 position에 대한 naive transition linearization이 대략 \(O((3n+m)^3)\)이고 state와 대칭성까지 커진다는 점입니다. 따라서 C12 규모에서는 monolithic QAP보다 9-A의 bin master + single-route oracle이 더 현실적입니다.

Dummy가 단순한 zero-size item 또는 unused-bin 표시일 뿐이면 \(y_q\)와 동일하여 LB를 전혀 강화하지 않는다는 점도 중요합니다.
